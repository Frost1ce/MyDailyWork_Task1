# Console-Based To-Do List

A simple and structured Python command-line application that allows users to create, manage, and track tasks efficiently.
The program uses a dictionary-based data structure to store tasks with unique IDs and completion status.

## Features
- Create a new to-do list
- Add new tasks
- Mark task as completed
- Remove individual tasks
- View tasks(seperated into Pending and Completed)
- Delete entire list with confirmation
- Input validation and error handling

## Technologies Used
- Python
- Sublime Text Editor

## How To Run
1. Make sure Python 3 is installed
2. Compile and Run the program:

     python ToDoList(Task1).py
